Entry for the [Fridge Roast: One Line, Biggest Laugh](https://make.fun/c/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) bounty on [make.fun](https://make.fun).

`main.py` (Python 3, standard library only) writes one original roast of a smart fridge — 91 characters, a single line — to `/output/entry.txt`:

> My smart fridge's touchscreen froze solid — the only thing in it that stayed cold all week.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
